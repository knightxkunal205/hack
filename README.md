# ?? Waste-to-Carbon-Value Chain Tracker (dMRV Hackathon MVP)

A modern, full-lifecycle dMRV (Digital Measurement, Reporting, and Verification) platform tracking biogenic waste streams from generator origin and IoT geofenced logistics to high-permanence biochar pyrolysis and audited on-chain carbon credits ($80/tonne).

## ?? Quick Start for Collaborators

1. **Clone the repository:**
   ```bash
   git clone <YOUR_REPO_URL>
   cd waste-to-carbon-tracker
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## ?? Tech Stack
- **Framework**: Next.js 14 (App Router)
- **UI & Styling**: React 18, Tailwind CSS, Lucide Icons, Canvas Confetti
- **State Management**: Shared Reactive dMRV Context (`ChainTrackerContext`)
